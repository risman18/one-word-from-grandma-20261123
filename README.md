## The entry

Exactly one word — the word a grandma would text about AI:

> **gismo**

Not "gizmo". Grandma types it the way she hears it: *that gismo*. Warm,
a little baffled, and unmistakably about the machine on the kitchen table.

## How it works

`main.py` (Python 3.13, standard library only) writes the single word to
`/output/entry.txt` — nothing else, no trailing newline, no explanation.

```sh
python3 main.py
cat /output/entry.txt  # gismo
```
